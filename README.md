# Borrow & Rent Neighbour

A peer-to-peer marketplace where neighbours can rent out items they own and borrow items they need.

## Features

- User registration and login
- Browse available items
- Add and manage item listings
- Search and explore items
- Book items for rent
- Wishlist management
- Booking management
- Notifications
- Admin category management

## Technology Stack

- React.js
- JavaScript
- Tailwind CSS
- Vite
- Axios

## Getting Started

1. Clone the repository.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

## Project Purpose

To make borrowing and renting convenient, affordable, and accessible within local communities.
